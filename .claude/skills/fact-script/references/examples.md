# Fact worked example: The Cook Who Spun Every Egg

Written for this kit with the Fact story template and animated end to end (`samples/fact-the-cook-who-spun-every-egg/`).
It shows the bar, the shape and the notes. Write new scripts from new topics instead of reusing it.

**Type:** Fact · **Format:** Fact story (a parable around a real mechanism) · **Length:** 65 s · **Words:** 239 (≈3.7 words/s)
**Logline:** On his first diner shift a new cook spins every egg instead of cracking them, because a spin tells a raw
egg from a boiled one without breaking it, and the last boiled egg stands up on its tip.

| Beat | Line | Note |
|---|---|---|
| 1. Hook | He spun every egg in the diner before he cracked a single one. | The deed, past tense, no name, 13 words. Picturable; makes you ask "why would he?" |
| 2. Setup | You see, it's his first shift, and someone just dumped the boiled eggs and the raw eggs into the same crate. And the lunch rush wants egg salad in twenty minutes. | Switch to present tense. The problem and the deadline, both as text props (crate stencil, order ticket, clock) |
| 3. Escalation | So he sets an egg on the counter and gives it a spin. | "So" chains it to the setup |
| | The cooks stop flipping pancakes to stare. Is he hypnotizing the breakfast? | The crowd reacts; a joke as a question in the narrator's voice |
| | But he doesn't look up, he just spins, watches, and drops each egg into one of two bowls, faster and faster, like a card dealer. | The run-on sentence that speeds up; a comparison joke |
| | Then the boss storms in, because table nine has waited so long, they've started reading the menu out loud to each other. | Pressure, with an exaggeration joke that's a picture |
| | So he grabs one more egg, spins it, stops it dead with one finger, lets go, and the egg starts turning again all by itself. Raw. | **The plant:** the mechanism shown before it's explained. A one-word jab lands it |
| 4. Mystery | But how does a spin tell you what's inside? | The viewer's question, out loud |
| 5. Reveal | Well, a boiled egg is solid, so the shell and the inside turn together, smooth as a top. A raw egg is liquid inside, so it sloshes and drags and the egg wobbles. Stop the shell, and the liquid keeps swirling, so it pushes the shell right back into a spin. | One mechanism, plain words, each sentence answering a picture already seen |
| | And in real life, chefs really check eggs this way. | The line that says what is real (the diner is invented) |
| 6. Payoff | And for the last boiled egg, he spins it as hard as he can, until it slowly rises onto its tip and keeps spinning, standing straight up. | A visual payoff that is also true (and surprising). Ends on the last word |
