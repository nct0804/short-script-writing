# Lesson 0 · Start here

**Fact & Fable** is a kit for writing short-video scripts with Claude (Reels, TikTok, YouTube Shorts), built from
measuring what the most-viewed faceless animated story channels actually do: how fast they talk, how long their
sentences are, what sentence 1 looks like, where the twist lands, how often they cut.

## What you get
| | |
|---|---|
| **4 skills** | `short-script` (start here: asks Fact or Fable), `fact-script`, `fable-script`, `study-references` |
| **2 script types** | **Fact**: real things told as mini-stories · **Fable**: invented worlds with one impossible rule |
| **5 formats** | Fact story, Fact event, Fact explainer · Fable story (warm or eerie), Fable gag |
| **This course** | 7 lessons: the two types, writing each one, learning from your own references, from script to video |
| **2 animated samples** | one Fact and one Fable script, each taken all the way to a finished vertical video (`samples/`) |

## Install (pick one)
- **Claude Code (recommended: everything works, including studying your own reference videos):** clone or download
  this folder and open it in Claude Code. The skills in `.claude/skills/` load automatically. To use them in every
  project, copy the four folders from `.claude/skills/` into `~/.claude/skills/`.
- **Claude.ai / the Claude app:** upload the zips from `dist/` under Settings → Capabilities → Skills (one zip per skill;
  start with `short-script.zip`, `fact-script.zip` and `fable-script.zip`). The reference-video study needs a computer
  with ffmpeg, so it's a Claude Code feature.

## Your first script in 5 minutes
1. Say: **"Write me a short script."**
2. Claude asks: **Fact or Fable?** Pick one (Lesson 1 explains the difference).
3. Give an idea in one line, or say **"pitch me"**.
4. Pick from the hook or rule options Claude offers.
5. You get the full script with timestamps, a shot list for the first 7 seconds, caption notes and a score card. Ask
   for changes in plain words ("darker ending", "make the hook shorter", "a 36-second version").

## The route through the course
| Lesson | You learn |
|---|---|
| 1 · Fact vs Fable | which type fits an idea, and why they never blur |
| 2 · Writing a Fact script | the deed hook, So/But/Then, the mystery, the reveal, the payoff, the facts table |
| 3 · Writing a Fable script | the rule, the misfit, the loved one and the ritual, the turn, the callback; the gag |
| 4 · Learning from reference videos | measuring the videos you admire, building your own style profile |
| 5 · From script to video | voice pace, captions, the shot list, what the samples teach |
| 6 · Cheat sheets | every number and checklist on two pages |

## Three rules the whole kit follows
1. **Sentence 1 is the whole hook.** The deed (Fact) or the rule (Fable). Nothing before it.
2. **Every script is scored** against its checklist and shipped at 85/100 or more.
3. **Original work only.** The kit learns patterns, never lines. It never copies another creator's lines, titles, plots
   or characters, and it never names the creators whose videos were studied.
